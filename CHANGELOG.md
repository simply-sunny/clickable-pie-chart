# Changelog

All notable changes to Clickable Pie Chart are documented here. This project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-26

### Added

- Mouse navigation for the F3 profiler pie chart: hold `Shift` to free the cursor, click any entry or slice to drill in.
- Right-click, or clicking `[0]`, to go back to the parent category.
- Hover highlights on list rows and pie slices, so the click target is always visible.
- Mouse wheel cycling: scroll over the chart to walk through entries, click the picked one to enter; moving the mouse returns to hover picking.
- `Shift` with a number key as a shortcut for 10–19, e.g. `Shift + 2` selects `12`.
- `~` toggles cursor mode without holding `Shift`.
- A hint bar at the bottom of the chart that shows which mode is active.
